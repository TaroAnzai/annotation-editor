# 麻雀牌アノテーション確認・修正ツール

ローカルの`data/`内にあるYOLOアノテーションを、画像と重ねて確認・修正するWebアプリです。元画像は読み取り専用です。AIが作成したBBoxの牌種だけをパレットから直す作業を中心に設計しています。

## 画面構成

左にフォルダーツリー、中央に画像とBBox、右にBBox一覧と牌種パレットを表示します。左右の境界はドラッグで幅を変えられます。中央上部のボタンで画像を絞り込みます。進捗と保存操作は画面下部にあります。

## 必要な環境と初回セットアップ

UbuntuなどのLinux、Python 3.10以上、Node.js 20以上、npm、ブラウザが必要です。初回インストール時のみインターネット接続が必要です。

```bash
cd annotation-editor
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cd frontend
npm install
cd ..
./start.sh
```

ブラウザで <http://localhost:5173> を開きます。Backendは127.0.0.1:8000、Frontendは127.0.0.1:5173で待ち受けます。終了は起動した端末で`Ctrl+C`です。両ポートが使用中なら起動しません。

## フォルダー選択と作業

左の`data`ツリーでフォルダーを選びます。親フォルダー、`roboflow_import`、`images`のいずれからも同じデータセットを開けます。複数の候補がある場合は左下の一覧から選んでください。`images/`、`labels/`、`data.yaml`が揃うフォルダーのほか、ルートの`data.yaml`と`train/images`・`train/labels`などの分割フォルダーを編集対象として検出します。画像だけのフォルダーは閲覧専用です。`roboflow_import_preview`は編集対象から除外します。画像は自然順です。ラベルがない画像も表示され、BBoxは0個から追加できます。

BBoxを画像または右の一覧で選択し、牌種パレットをクリックすると即時に牌種が変わります。パレットのクラスIDは`data.yaml`の`names`に従います。牌画像がない場合は文字で表示します。「自動で次へ」を有効にすると次のBBoxに選択が移ります。BBoxをドラッグして移動、黄色のハンドルでサイズ変更、画像の空白をドラッグして追加します。追加したBBoxは牌種パレットで正しい牌種を指定してください。ホイールで拡大縮小できます。拡大時はAlt+ドラッグまたは中ボタンでパンできます。「画面にフィット」と「100%表示」のボタンもあります。

「保存」はYOLOラベルだけを保存し、確認状態は変えません。「確認済み・次へ」は保存して確認済みにし、次の画像へ進みます。最後の画像では完了表示になります。「保留」は作業状態を保留にします。未保存変更を伴う画像・フォルダー切替や保留時には保存、破棄、キャンセルを選べます。ブラウザを閉じる際も未保存変更を警告します。

## キーボード

| キー | 操作 |
|---|---|
| 左/右矢印 | 前/次の画像 |
| Tab / Shift+Tab | 次/前のBBox |
| Delete | 選択中のBBoxを削除 |
| Escape | 選択解除 |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z、Ctrl+Y | Redo |

## 保存形式と安全性

ラベルは`class_id x_center y_center width height`で、座標は0～1の正規化値です。保存時にクラス、座標、BBoxの画像内収まりを検証します。既存ラベルを変更する場合、変更前を`annotation-editor/backups/`にデータセットの相対パスを保った世代付きファイルとして保存します。一時ファイルに書き込み、検証後に原子的に置換します。元ラベルに読込エラーがあれば保存を止めます。外部でラベルが変わっていればHTTP 409で保存を止め、再読込を促します。画像は変更しません。確認状態は`annotation-editor/state/`のJSONに保存されます。

テストは一時ディレクトリにデータセットを作り、実際の`data/`には書き込みません。

## トラブルシューティング

- 起動時に依存がないと表示された場合、初回セットアップを実行してください。
- ポート使用中の場合、既存の起動プロセスを終了してください。
- ラベルエラーや`data.yaml`エラーは画面に表示されます。元ファイルを確認してください。エラーのあるラベルは自動修正されません。
- 保存時の競合エラーは、外部でラベルが更新されたことを示します。表示を再読込して内容を確認してください。
- 書込権限エラーでは元ラベルは維持されます。データセットと`annotation-editor/`の権限を確認してください。

このレポジトリはGit管理されています。`.gitignore`で仮想環境、依存パッケージ、ビルド成果物、`backups/`、`state/`を除外しています。元データの`../data/`はこのレポジトリの外にあります。元データとバックアップはGitへ追加しないでください。
